# Quantitative Trading

A quantitative finance and AI-based trading system built using Python.

## Features

- Geometric Brownian Motion Simulation
- Monte Carlo Market Paths
- Feature Engineering
- Machine Learning Trading Signals
- AI-Based Trading Model
- Portfolio Optimization
- VaR / CVaR Risk Metrics
- Backtesting Engine
- Strategy Visualization

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- yFinance

## Run Project

python main.py
